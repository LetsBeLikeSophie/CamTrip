# CamTrip 개인정보처리방침

[운영자 이름](이하 "운영자")은 CamTrip 앱(이하 "앱")을 쓰는 분의 개인정보를 「개인정보 보호법」에 따라 보호하고,
관련 고충을 빨리 처리할 수 있도록 이 방침을 둡니다.

## 한눈에 보기

- 사진은 폰 안에서만 읽고 번역해요. 사진은 밖으로 나가지 않아요.
- 딱 하나 예외: **"AI로 읽기"** 버튼을 누르고 고른 네모 안쪽만, 보내기 전 미리보기로 보여드린 뒤 보내요.
- AI 기능(하루 페이지, 저녁 정리, 메뉴 설명)을 쓸 때는 **글자만** 보내요.
- 서버는 받은 내용을 처리해서 답을 돌려준 뒤 **저장하지 않아요**.
- 회원가입이 없어요. 이름, 전화번호, 이메일을 받지 않아요.
- 위치 정보를 쓰지 않아요. 광고가 없어요.
- 사용 기록은 동의한 분만, 무엇을 몇 번 눌렀는지만 남겨요. 지금은 폰 안에만 있어요.

## 1. 개인정보의 처리 목적

운영자는 아래 목적으로만 개인정보를 처리하고, 목적이 바뀌면 미리 알리고 필요한 경우 동의를 받습니다.

1. AI 기능 제공: AI 하루 페이지, 저녁 정리, 메뉴 설명, AI로 읽기
2. 유료 이용권·크레딧 확인과 복원, 환불 처리
3. 지나친 사용 막기(하루 사용 한도), 오류 확인
4. (동의한 경우만) 앱 개선을 위한 사용 기록 분석

## 2. 처리하는 개인정보 항목

### 2-1. 폰 안에만 있는 것 (운영자에게 오지 않음)

| 항목 | 설명 |
|---|---|
| 찍은 사진 | 앱 폴더에 저장. 글자 인식·번역은 폰 안(Google ML Kit)에서 함 |
| 인식·번역한 글자, 영수증 항목·금액 | 여행 기록으로 저장 |
| 말하기 메모 | 말한 내용을 글자로만 저장. 녹음 파일은 남기지 않음 |
| 여행 정보 | 나라·도시(직접 입력), 날짜, 화면 색 |
| 사용 기록(동의 시) | 어떤 기능을 언제 썼는지만. 사진·메모·번역 내용은 담지 않음 |

음성 인식은 폰의 음성 인식 기능을 써요. 폰 설정에 따라 폰 제조사·Google의 음성 인식 서비스가 처리할 수 있어요. [출시 전 확인: 기기 내 인식만 쓰도록 설정할지]

번역 모델은 처음 한 번 Google에서 내려받아요. 이때 사진이나 글자는 보내지 않아요.

### 2-2. 서버로 보내는 것

| 언제 | 보내는 항목 | 필수/선택 |
|---|---|---|
| AI 하루 페이지 | 그날 기록의 번역된 글자, 영수증 항목·금액, 메모 글자, 시각, 여행 나라·도시·몇째 날 | 기능을 쓸 때만 |
| 저녁 정리 | 말하기 메모 글자와 시각 | 기능을 쓸 때만 |
| 메뉴 설명 | 요리 이름(원문·번역) | 기능을 쓸 때만 |
| AI로 읽기 | 사용자가 고른 네모 안쪽을 잘라낸 이미지 1장 (위치 등 사진 정보 지움) | 버튼을 누르고 확인할 때만 |
| AI 기능·구매 시 | 익명 기기 ID(앱이 만든 무작위 번호), 앱 버전 | 필수 |
| 구매 시 | Google Play 구매 토큰, 상품 종류, 주문 번호, 여행 구분용 무작위 키 | 필수 |
| 접속할 때 자동으로 | IP 주소, 접속 시각, 오류 기록 | 필수 |

받지 않는 것: 이름, 전화번호, 이메일, 위치, 연락처, 사진 원본, 광고 ID.
결제 카드 정보는 Google Play가 처리하고 운영자는 받지 않아요.

보낸 글자나 이미지 안에 다른 사람 이름 같은 정보가 들어 있을 수 있어요. 보내기 전에 화면에서 확인할 수 있어요.

## 3. 보유 및 이용 기간

| 항목 | 기간 |
|---|---|
| AI 기능으로 보낸 글자·이미지, AI 답 | **저장하지 않음.** 답을 돌려준 즉시 메모리에서 버림 |
| 익명 기기 ID, 이용권·크레딧 기록 | 마지막 사용 후 [1년], 또는 지우기 요청 시 바로 |
| 구매 토큰·주문 번호 | 거래 기록으로 [5년] (「전자상거래 등에서의 소비자보호에 관한 법률」 — 기간 확인 필요) |
| 하루 사용 횟수 | 90일 |
| IP 주소가 담긴 접속 기록 | 14일 |
| 메뉴 설명 결과 | 요리 이름과 설명만, 기기와 연결하지 않고 보관 (개인정보 아님) |
| 폰 안 정보 | 사용자가 지우거나 앱을 지울 때까지 |

AI 처리 업체(Anthropic)의 보관 기간은 4번을 봐 주세요.

## 4. 처리 위탁 및 국외 이전

운영자는 서비스를 위해 아래 업체에 처리를 맡깁니다. 서버와 AI가 한국 밖에 있어서 **국외로 이전**돼요.
AI 기능을 쓰지 않으면 2-2의 AI 관련 항목은 이전되지 않아요.

| 받는 곳 | 나라 | 하는 일 | 이전 항목 | 이전 시기·방법 | 보유 기간 |
|---|---|---|---|---|---|
| Anthropic, PBC ([연락처]) | 미국 | AI 하루 페이지·저녁 정리·메뉴 설명·AI로 읽기 처리 | 2-2의 기능별 글자, AI로 읽기 이미지 | 기능을 쓸 때마다, 암호화된 통신(HTTPS) | [Anthropic 약관 확인 필요 — 학습에 쓰지 않는지, 며칠 보관하는지] |
| Oracle Corporation ([연락처]) | 일본 (도쿄 리전) | 서버 운영(호스팅) | 2-2 전체 (처리 중 잠시), 기기 ID·구매 기록 | 앱이 서버에 접속할 때, HTTPS | 3번 기간과 같음 |
| Google LLC ([연락처]) | 미국 등 | Google Play 결제, 구매 확인 | 구매 토큰, 주문 정보 | 구매·확인 시, HTTPS | Google 방침에 따름 |

국외 이전을 원하지 않으면 AI 기능과 유료 결제를 쓰지 않으면 돼요. 폰 안 기능(찍기·번역·영수증·말하기)은 그대로 쓸 수 있어요.
[출시 전 확인: 국외 이전에 별도 동의를 받을지, 방침 공개로 충분한지 — 「개인정보 보호법」 제28조의8]

운영자는 이용자의 개인정보를 위 경우 말고는 제3자에게 제공하지 않습니다. 법령에 따른 요청이 있으면 예외예요.

## 5. 개인정보의 파기

- 기간이 끝나거나 목적을 이루면 바로 지워요.
- 서버 데이터는 다시 살릴 수 없게 지우고, 법으로 보관해야 하는 구매 기록은 기기 ID와 끊어서 따로 보관해요.

## 6. 이용자의 권리와 행사 방법

언제든 아래를 할 수 있어요.

- **서버에 있는 내 정보 보기·지우기**: 앱 설정 → "서버에 있는 내 정보 지우기". 기기 ID, 크레딧·이용권 기록, 사용 횟수가 지워져요. (산 이용권은 Google Play 구매 내역으로 다시 복원할 수 있어요.)
- **사용 기록 동의 철회**: 앱 설정에서 끄기. 그동안 모은 기록도 지울 수 있어요.
- **폰 안 기록 지우기**: 여행·사진·메모를 앱에서 지우거나 앱 삭제.
- 열람, 정정, 삭제, 처리 정지 요구는 [이메일]로도 할 수 있고, 운영자는 10일 안에 답해요.
- 대리인을 통해서도 할 수 있어요 (위임장 필요).

회원가입이 없어서 운영자는 누가 누구인지 알 수 없어요. 요청할 때 앱 설정에 보이는 기기 ID 앞자리를 알려주시면 찾을 수 있어요.

## 7. 만 14세 미만 아동

앱은 만 14세 미만 아동을 대상으로 하지 않아요. 유료 결제는 Google Play의 보호자 설정을 따라요.
만 14세 미만 아동의 개인정보를 처리한 사실을 알게 되면 바로 지워요.

## 8. 안전성 확보 조치

- 모든 통신은 HTTPS로 암호화
- AI로 보낸 내용은 저장하지 않음, 로그에 내용 남기지 않음
- 서버 접근은 운영자 1명, 키 인증으로만 접속
- AI·결제 API 키는 서버에만 두고 앱에 넣지 않음
- 사용 한도와 요청 크기 제한
- 정기적인 보안 업데이트

## 9. 개인정보 자동 수집 장치

## 부록 (내부용 메모 — 공개본에는 각 나라 언어로 따로 씀)

### EU 사용자 (GDPR) — 영어권·EU 출시 때

- 처리 근거: AI 기능·구매 = 계약 이행(제6조 1항 b), 남용 방지·오류 확인 = 정당한 이익(f), **사용 기록 = 동의(a)**.
- 사용 기록은 지금처럼 **기본 꺼짐 + 따로 묻기**. 거절해도 기능 차이 없게. 철회는 동의만큼 쉽게(설정 한 번).
- 미국(Anthropic, Google)으로 이전: 받는 쪽이 EU-US Data Privacy Framework 인증인지, 아니면 표준계약조항(SCC)을 쓰는지 확인해서 적기.
- 권리 추가 안내: 접근, 정정, 삭제, 처리 제한, 이동권, 반대권, 감독기관 민원.
- EU 대리인(제27조) 필요 여부 확인.
- 만 16세 미만(나라별 13~16세) 동의 연령 확인.

### 일본 사용자 (APPI) — 일본 출시 때

- 이용 목적을 구체적으로 공표(위 1번과 같음).
- 외국(미국)의 제3자 제공·위탁: 받는 나라 이름, 그 나라 개인정보 제도에 대한 정보, 받는 쪽의 보호 조치를 알려야 함(외국 제3자 제공 시 본인 동의 또는 기준에 맞는 체제 정비).
- 개인정보 취급 사업자의 이름·주소·대표자 공표 항목 확인.
- 보유 개인 데이터의 공개·정정·이용 정지 청구 창구.
- 서버가 일본(도쿄)에 있다는 점은 일본 사용자에게는 국외 이전이 아님 — Anthropic·Google 쪽만 해당.

### 대만 (PDPA) — 대만 출시 때

- 수집 시 고지 항목(목적, 항목, 기간·지역·대상·방법, 권리) 확인 필요.

# CamTrip 시제품 (v0.1)

찍기 → 번역 → 자동 저장 → 여행 목록까지만 되는 시제품이에요.
글자 인식과 번역은 모두 폰 안에서 해요 (Google ML Kit). 서버, API 키, 결제는 아직 없어요.

## 되는 것

- 카메라로 찍거나 갤러리에서 골라 번역 (일본어, 중국어, 한국어, 영어·유럽어 글자)
- 사진 위에 번역 덮어쓰기, 원문/번역 전환
- 번역마다 자동 저장, 카테고리 자동 추측 (탭해서 수정)
- 새 언어이거나 3일 넘게 쉬었다 번역하면 "새 여행인가요?" 묻고 나라·도시 입력
- 여행 목록, 여행별 사진 모아보기, 카테고리 필터, 여행 지우기
- 설정: 번역할 언어 고르기 (기본은 폰 언어)

## 아직 없는 것

의미 설명, 사진에 질문, 답장 카드, 경비, 여행기, 결제. 이것들은 서버와 Claude API를 붙이는 다음 단계에서 만들어요.

## 실행 방법 (Windows + Android Studio)

Android 틀, ML Kit 글자 모델, 인터넷 권한은 이미 들어 있어요.

1. 프로젝트 폴더에서 `flutter pub get`을 실행해요.
2. 폰을 USB로 연결하고 (개발자 옵션 → USB 디버깅 켜기) `flutter run` 또는 Android Studio에서 ▶ 실행.
3. 테스트는 `flutter test`로 돌려요.

## 처음 쓸 때

- 언어별 번역 모델(약 30MB)을 처음 한 번 내려받아요. Wi-Fi에서 처음 써보세요.
- 그다음부터는 비행기 모드에서도 번역돼요.

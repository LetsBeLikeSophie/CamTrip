# CamTrip 시제품 (v0.1)

찍기 → 번역 → 자동 저장 → 여행 목록까지만 되는 시제품이에요.
글자 인식과 번역은 모두 폰 안에서 해요 (Google ML Kit). 서버, API 키, 결제는 아직 없어요.

## 웹 미리보기

https://itssophie.dev/camtrip/ — 브라우저에서는 카메라·ML Kit를 쓸 수 없어서, 웹(`kIsWeb`)에서는
샘플 사진(`assets/demo`, `lib/demo.dart`)으로 화면과 흐름만 보여줘요. 웹 기록은 저장되지 않아요.
빌드: `flutter build web --release --base-href /camtrip/` (Git Bash에서는 앞에 `MSYS_NO_PATHCONV=1`).

## 테스트 APK

https://itssophie.dev/camtrip/download.html (안내 페이지 `web/download.html`) → `camtrip.apk`. arm64 전용, 디버그 키 서명.
새 APK를 올리면 `pubspec.yaml` 버전과 `web/download.html`의 버전·크기·SHA-256도 같이 고쳐요.
웹을 다시 올릴 때 서버 폴더를 통째로 지우면 APK도 지워지니 주의.

## 되는 것 (0.2, 폰 안에서만)

- 처음 켰을 때 안내 + 사용 기록 동의(선택)
- 홈: 지금 여행을 날짜별 기록으로. 아래 [찍기] [누르고 말하기] 두 띠
- 찍으면 글자 종류를 자동으로 알아내 번역하고, 메뉴/영수증도 자동으로 나눔 (틀리면 "영수증이에요/아니에요")
- 뜻 보기: 사진을 누르고 있는 동안만 번역 띠가 보임, 줄마다 현지어 듣기, 답장 카드
- 영수증: 합계·항목 자동 읽기, 고치기, 분류 → 경비 합계에 들어감
- 누르고 말하기: 말한 내용을 글자로만 저장(녹음 안 남김), "2,800엔" 같은 금액은 경비로 셈
- 여행마다 대표 사진에서 색 4개(밝은 2·진한 2)를 뽑아 화면 색으로 씀, 여행 목록은 대표 사진 띠
- 새 여행 자동 시작, 여행 목록·상세, 설정
- 저녁 정리: 말로 남긴 메모를 경비/하루 문장으로 나눠 보여주고 "맞아요"·고치기 (폰 안 규칙), 매일 알림(기본 21:00, 설정에서 변경)
- 음성 메모 보기·고치기, 글자를 못 읽었을 때 안내 화면
- 로고(D안: 네 칸 띠 위의 CT) — 앱 아이콘·적응형/테마 아이콘·알림 아이콘·스플래시·웹 아이콘. 다시 만들 때 `python tools/make_icons.py .`

## 아직 없는 것

AI 하루 페이지(서버 + Claude API 필요, 계획은 `docs/ai-server-plan.md`), 현지인에게 묻기·AI로 읽기, 크레딧·결제, 릴스·PDF. 개인정보처리방침 초안은 `docs/privacy-policy-draft.md`.

## 실행 방법 (Windows + Android Studio)

Android 틀, ML Kit 글자 모델, 인터넷 권한은 이미 들어 있어요.

1. 프로젝트 폴더에서 `flutter pub get`을 실행해요.
2. 폰을 USB로 연결하고 (개발자 옵션 → USB 디버깅 켜기) `flutter run` 또는 Android Studio에서 ▶ 실행.
3. 테스트는 `flutter test`로 돌려요.
